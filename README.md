# Snake Game

A responsive browser Snake game with keyboard, swipe and touch controls, three difficulty levels, pause/resume, and a personal best saved in the browser.

## Play locally

Open `index.html` in a modern browser. No installation or build step is required.

## Controls

- Arrow keys or WASD: move
- Enter: start or replay
- Space: pause or resume
- Mobile: swipe the board or use the on-screen arrows

Collect fruit for 10 points. Avoid the walls and your own body.

## Upload to GitHub

1. Create a repository named `snake-game` in your GitHub account.
2. Extract this ZIP on your computer.
3. In the repository, select **Add file > Upload files**.
4. Upload `index.html`, `README.md`, and `.nojekyll` from the extracted folder.
5. Commit the files.

## Publish with GitHub Pages

1. Open the repository's **Settings > Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select the `main` branch and the `/ (root)` folder, then save.
4. Open the website URL displayed by GitHub once deployment completes.

Keep `index.html` at the repository root. The game uses relative-free local code and works under a GitHub Pages repository path.

## Files

- `index.html`: complete HTML, CSS, and JavaScript source
- `README.md`: setup, controls, and publishing instructions
- `.nojekyll`: disables Jekyll processing for static hosting

Google Fonts is an optional external stylesheet; system fonts are used if it is unavailable. Scores are stored locally on each browser, not on a server.
